# Tic Tac Toe (Хрестики-Нулики)

Класична гра Хрестики-Нулики, розроблена на C++ з використанням бібліотеки **SFML**.

## Особливості гри
* Гра для двох гравців на одному екрані (Хрестики та Нулики).
* Звуковий супровід для ходів, паузи, перемоги та нічиєї.
* Можливість поставити гру на паузу (`P`) та перезапустити після завершення (`R`).

## Керування
* **Ліва кнопка миші** — зробити хід (поставити фігуру).
* **Клавіша P** — увімкнути / вимкнути паузу.
* **Клавіша R** — перезапустити гру після закінчення партії.

## Вимоги для збірки
* Компілятор C++ з підтримкою стандарту C++17 або вище.
* Бібліотека **SFML** (версії 2.5 або 2.6).

## Структура проєкту
* `Font/` — шрифти для інтерфейсу.
* `Sounds/` — звукові ефекти (`.wav`).
